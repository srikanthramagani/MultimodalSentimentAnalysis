# Sample Files

Place sample images here for manual testing. Supported formats: JPEG, PNG.

The repository does not include sample images to keep the repo lightweight. You can use any JPEG or PNG image for testing through the web interface.

Suggested test cases:
- A photo of a smiling person (expected: positive sentiment from caption)
- A photo of stormy weather or a dark scene (expected: negative or neutral)
- A neutral everyday object (expected: neutral)
